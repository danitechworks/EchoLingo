# EchoLingo frontend

The React and TypeScript client for EchoLingo. It displays quotes, localizes the interface, translates the active quote, and provides responsive light and dark desk scenes.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run lint
```

The development server runs at `http://localhost:5173`. API requests beginning with `/api` are proxied to the backend URL configured in `vite.config.ts`.

See the [repository README](../README.md) for the full project setup and API details.
